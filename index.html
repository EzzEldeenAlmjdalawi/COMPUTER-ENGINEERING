معمارية الحاسوب والأنظمة المدمجة

دراسة تصميم المعالجات، المتحكمات الدقيقة (Microcontrollers)، لغات توصيف العتاد VHDL، ورقاقات FPGA، ولغة التجميع Assembly.

البرمجة وهندسة البرمجيات

البرمجة الكائنية المتقدمة OOP، هياكل البيانات المعقدة، تحليل وتصميم الخوارزميات، وهندسة النظم وقواعد البيانات العلائقية.

C++ / Java Data Structures Algorithms SQL & DB

شبكات الحاسوب وإنترنت الأشياء

بروتوكولات الإنترنت TCP/IP، توجيه البيانات Routing & Switching، شبكات الحساسات اللاسلكية، وتطبيقات إنترنت الأشياء الذكية IoT.

TCP/IP Cisco Routing IoT Protocols Wireless Sensors

الذكاء الاصطناعي وتعلم الآلة

الشبكات العصبية الاصطناعية، التعلم العميق Deep Learning، معالجة الصور الرقمية، وخوارزميات الرؤية الحاسوبية ومعالجة اللغات الطبيعية.

Neural Networks Deep Learning Computer Vision Image Processing

أمن المعلومات والسيبرانية

علم التشفير Cryptography، حماية الشبكات والخوادم، تحليل الثغرات الأمنية، والمصادقة الرقمية وحماية البيانات من الهجمات السيبرانية.

Cryptography Network Defense Authentication Ethical Hacking

نظم التشغيل والتحكم الرقمي

بنية أنظمة التشغيل وإدارة العمليات والذاكرة (Linux/Unix)، أنظمة الزمن الحقيقي RTOS، ونظم التحكم الآلي والإشارات الرقمية DSP.

Linux / Unix Kernel RTOS Linear Control Signals & Systems
